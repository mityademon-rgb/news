БУМ.КАДР — статический сайт школы

Публикация:
1. Загрузите всё содержимое папки dist в корневую папку сайта на сервере.
2. Главный файл — index.html. Сборка и база данных не нужны.
3. Сайт работает по HTTPS или HTTP на обычном статическом хостинге.

Добавление уроков:
- данные и сценарии находятся в lessons.js;
- изображения находятся в assets;
- новый урок добавляется как новый объект в массив BOOM_LESSONS.

Сохранение прогресса:
- прогресс хранится только в браузере конкретного устройства (localStorage);
- регистрация и серверная база данных в этой версии не используются.
